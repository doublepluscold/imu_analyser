# Калібрація IMU-модуля: що записати і якими командами

Усе виконується з папки проєкту (`~/embed/imu/eps_imu_demo`) через `uv run`.
Програма тільки слухає порт і нічого не надсилає в модуль.
Кожен запис - це звичайна сесія в `logs/<дата>_<мітка>/`, яку можна переглянути через `uv run imu replay`.

## 0. Перед початком

- Модуль живиться від БЖ 24 В, адаптер під'єднано з RS232-боку, порт `/dev/ttyUSB0`.
- Порт одночасно може читати лише одна програма. `mtdata2_decoder.py` і `imu` разом не запускати.
- Один раз домовся сам із собою про сторони плати і позначки на ній: де ПЕРЕД (ніс), де ВЕРХ. Далі тримайся цього у всіх записах.
- Перевір, що дані йдуть:
  ```
  uv run imu live --no-record
  ```
  У Rerun має бути |a| близько 9.8 і живі графіки Euler. Вихід - `q` або Ctrl+C.

## 1. Записи (крок 4: перевірка даних, гіро, осі)

Під час кожного запису плату не торкатися, стіл без вібрацій.

1. Спокій, 60 с, плата лежить рівно верхом догори:
   ```
   uv run imu calib record --label still --seconds 60
   ```
2. Шість положень, по 15 с кожне. Назва каже, яка сторона дивиться ВНИЗ (як у Mission Planner):
   | мітка | положення |
   |---|---|
   | `pose_level` | рівно, верх догори |
   | `pose_back` | догори дригом, верх донизу |
   | `pose_left` | на лівому боці (лівий бік донизу) |
   | `pose_right` | на правому боці |
   | `pose_nosedown` | носом донизу (перед донизу) |
   | `pose_noseup` | носом догори (зад донизу) |
   ```
   uv run imu calib record --label pose_level --seconds 15
   uv run imu calib record --label pose_back --seconds 15
   ... (так само для решти)
   ```
   Плату можна обпирати на рівний брусок або коробку. Точно 90 градусів не потрібно, але вона має стояти нерухомо.
3. Три обертання, по 15 с кожне. Порядок у кожному: 3 с спокою, один поворот на 90 градусів навколо однієї осі, спокій до кінця запису.
   - `rot_z` - плата лежить рівно, повернути по столу на 90 градусів;
   - `rot_x` - перекинути з рівного положення на правий бік;
   - `rot_y` - підняти ніс на 90 градусів.
   ```
   uv run imu calib record --label rot_z --seconds 15
   uv run imu calib record --label rot_x --seconds 15
   uv run imu calib record --label rot_y --seconds 15
   ```

## 2. Аналіз (роблю я, або можна запустити самому)

```
uv run imu calib check logs/*_still logs/*_pose_* logs/*_rot_*
uv run imu calib gyro logs/*_still logs/*_rot_*
uv run imu calib axes logs/*_pose_*
uv run imu framing logs/*_still
```

- Якщо якусь позицію записав двічі, зайвий запис видали, інакше `logs/*_pose_*` підхопить обидва.
- Звіти зберігаються в `calib/reports/<дата>/`.
- `calib axes` тільки пропонує таблицю осей. У конфіг вона пишеться лише після мого і твого OK:
  ```
  uv run imu calib axes logs/*_pose_* --write config.toml
  ```
